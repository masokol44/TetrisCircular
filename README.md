🌀 TetrisCircular — круговой тетрис
Классический тетрис на цилиндрическом поле! Фигуры могут выходить за правую границу и появляться слева, создавая новые стратегические возможности.
Реализован на 7 языках программирования для демонстрации алгоритмов и работы с консолью.

🧠 Концепция
TetrisCircular — это вариант классического тетриса, где поле замкнуто по горизонтали (эффект «цилиндра»). Если фигура выходит за правый край, она появляется слева, и наоборот. Это добавляет новые тактические приёмы и делает игру более динамичной.

✅ Цилиндрическое поле — фигуры «перематываются» через края.

✅ Стандартные фигуры — все 7 тетрамино (I, O, T, S, Z, J, L).

✅ Управление — стрелки (влево/вправо) для движения, вверх для вращения, пробел для быстрого падения.

✅ Система очков — за очищенные линии.

✅ Уровни — скорость падения растёт с каждым уровнем.

✅ Следующая фигура — отображение следующего блока.

✅ Кроссплатформенность — работает в консоли на всех ОС.

🚀 Как запустить
Каждая версия использует минимальные зависимости. Установите их и запустите.

Python
bash
pip install keyboard
python tetris_circular.py
C++
bash
# Для Linux требуется ncurses (sudo apt install libncurses-dev)
g++ -std=c++17 tetris_circular.cpp -o tetris -lncurses
./tetris
Java
bash
javac TetrisCircular.java && java TetrisCircular
C#
bash
dotnet run
Go
bash
go mod init tetris
go get github.com/eiannone/keyboard
go run tetris_circular.go
Rust
bash
cargo new tetris
cd tetris
cargo add termion rand
cargo run
JavaScript (Node.js)
bash
npm install keypress
node tetris_circular.js

🔮 Расширенные функции
